# Justera hyra

När hyran ska ändras – till exempel vid årlig indexuppräkning – skapar Tenovo en ny version av kontraktet i stället för att skriva över det gamla. Versionshistoriken bevarar hela förändringskedjan så att du alltid kan se vilken hyra som gällt och från när.

Du kan justera hyran på två sätt: per kontrakt på avtalets detaljsida, eller i bulk för flera aktiva kontrakt samtidigt.

## Ändra hyra på ett kontrakt

1. Öppna hyreskontraktet från listan eller Kanban-vyn.
2. Klicka på **Ändra hyra** (visas för aktiva avtal).
3. Fyll i:
   - **Ny månadshyra (kr)** – det nya beloppet
   - **Gäller från** – ikraftträdandedatum för den nya hyran
   - **Kommentar (valfritt)** – till exempel *Årlig indexuppräkning*
4. Klicka på **Spara ny hyra**.

En ny version av kontraktet skapas med den nya hyran och ikraftträdandedatumet.

## Versionshistorik

På avtalets detaljsida visas alla versioner i en tidslinje. För varje version ser du:

- Versionsnummer
- Ikraftträdandedatum
- Status
- Ändringsbeskrivning
- Månadshyra för den versionen

Klicka på en äldre version för att öppna den. Det tidigare aktiva avtalet markeras som **Ersatt** när den nya versionen träder i kraft – direkt om ikraftträdandedatumet redan har passerat, annars först på det valda datumet.

## Justera hyra i bulk

För att justera hyran på flera aktiva kontrakt i ett steg:

1. Gå till **Hyreskontrakt** i huvudmenyn.
2. Markera de kontrakt som ska justeras med kryssrutorna i listan.
3. Klicka på **Justera hyra** i åtgärdsfältet.
4. Välj **Justeringstyp**:
   - **Procentuell justering** – till exempel 2,5 %
   - **Fast belopp** – till exempel 500 kr
5. Ange värdet och välj **Giltigt från**-datum.
6. Granska förhandsgranskningen – den visar hyresgäst, objekt, nuvarande hyra, ny hyra och skillnad per kontrakt.
7. Bekräfta för att skapa de nya versionerna.

<Note>
Bulkjusteringen skapar en ny version per markerat kontrakt med samma ikraftträdandedatum. Nya hyresaviseringar som genereras efter ikraftträdandedatumet använder den nya hyran.
</Note>
